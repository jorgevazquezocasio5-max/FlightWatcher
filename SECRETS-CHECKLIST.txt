SECRETS CHECKLIST  (for your own reference - DO NOT upload this file to GitHub)

Secrets are never stored in the zip or the repo files. You type them into GitHub:
  Repo > Settings > Secrets and variables > Actions > New repository secret

Create these 4 secrets (names must match exactly):

  Name           Value                                   Where to find it
  -------------  --------------------------------------  ------------------------------------
  TWILIO_SID     starts with AC...                       Twilio Console home > Account Info
  TWILIO_TOKEN   long string                             Twilio Console home > Account Info (eye icon)
  TWILIO_FROM    your Twilio number, e.g. +1XXXXXXXXXX   Twilio Console > Phone Numbers (SMS: plain number, no "whatsapp:")
  ALERT_TO       your phone, +1XXXXXXXXXX                the phone that receives the alerts
